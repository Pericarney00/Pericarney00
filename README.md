## 💼 Featured Projects

### 🎯 [Follow Forward](https://followforward.dev)

**Production Goal-Planning & Accountability Platform** | *2026* | 🌐 **[Live at followforward.dev](https://followforward.dev)**

A full-stack web app that helps people break large goals into ordered sub-goals, track deadlines, and actually follow through. Designed, built, secured, and shipped solo — my main focus right now.

> Source is private, but the app is live and free to try — and I'm always happy to walk through the architecture or code in a conversation.

**Tech Stack:** Next.js, TypeScript, PostgreSQL, Drizzle ORM, Tailwind CSS, AWS S3, Redis, Anthropic Claude API, Vitest, Vercel

**Key Features:**

- Secure per-user accounts with data-access controls, so each person can only reach their own data
- Four production LLM features on the Anthropic Claude API, with structured outputs enforced by Zod schemas for type-safe, reliable responses
- Full production surface around the AI: prompt design, token and cost control, Redis caching, rate limiting, graceful degradation, and per-tier entitlement gating
- End-to-end security audit — closed broken access-control flaws, tightened input validation, and added security headers, webhook signature verification, and rate limiting, raising the external security rating from **B+ to A**
- Image uploads via AWS S3, responsive light/dark UI, and an automated Vitest test suite
